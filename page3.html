หมู่ฟังก์ชันสำคัญอื่นๆ (Functional Group Derivatives)

1. มีธาตุ O เป็นองค์ประกอบ - แอลกอฮอล์ (-OH) -> ดึงดูดน้ำ (H-bond) / จุดเดือดสูง / + โลหะ Na -> แก๊ส H2 - อีเทอร์ (-O-) -> ไม่มี H-bond / จุดเดือดต่ำ / ไวไฟ / ตัวทำละลาย - แอลดีไฮด์ (-CHO) -> คาร์บอนิลปลายสาย / + เบเนดิกต์ -> ตะกอนแดงอิฐ - คีโตน (-CO-) -> คาร์บอนิลกลางสาย / ไม่ทำปฏิกิริยากับเบเนดิกต์ (เช่น อะซิโตน) - กรดคาร์บอกซิลิก (-COOH) -> กรดอ่อน / จุดเดือดสูงสุด / + NaHCO3 -> แก๊ส CO2 - เอสเทอร์ (-COOR) -> กลิ่นหอมผลไม้ / เกิดจาก กรด + แอลกอฮอล์ 2. มีธาตุ N เป็นองค์ประกอบ - เอมีน (-NH2) -> เบสอ่อน / กลิ่นคาวปลา - เอไมด์ (-CONH2) -> เป็นกลาง / แข็งแรง / พบในโปรตีน (พันธะเพปไทด์) เปรียบเทียบจุดเดือด: กรดคาร์บอกซิลิก > แอลกอฮอล์ > เอไมด์ > เอมีน > เอสเทอร์/คีโตน/แอลดีไฮด์ > อีเทอร์
